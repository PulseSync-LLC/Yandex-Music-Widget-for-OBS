## Что это такое?

Это набор красивых виджетов для OBS Studio, которые показывают информацию о треке, который сейчас играет в Яндекс.Музыке. Виджет автоматически обновляется и отображает:
- Название трека
- Исполнителя
- Обложку альбома
- Статус воспроизведения (играет, на паузе и т.д.)
- Прогресс трека

## Что нужно для работы?

**Всего 2 простых шага:**

1. **Установите PulseSync**
   - Скачайте приложение с официального сайта: [pulsesync.dev](https://pulsesync.dev/)
   - Установите его на компьютер
   - Запустите Яндекс.Музыку и PulseSync одновременно

2. **Выберите виджет**
   - Откройте файл `preview.html` в браузере, чтобы посмотреть все доступные виджеты
   - Выберите понравившийся дизайн

**Всё!** Больше ничего настраивать не нужно. Виджет автоматически подключится к PulseSync и начнёт показывать информацию о треках.

## Как добавить виджет в OBS?

### Пошаговая инструкция:

1. **Откройте OBS Studio**
   - Запустите программу OBS на вашем компьютере

2. **Добавьте Browser Source**
   - В списке источников (внизу экрана) нажмите кнопку **"+"** (плюс)
   - Выберите **"Browser Source"** (Браузерный источник)
   - Дайте ему название, например: "Яндекс Музыка"

3. **Укажите путь к виджету**
   - В настройках Browser Source найдите поле **"Local file"** (Локальный файл)
   - Нажмите кнопку **"Browse"** (Обзор)
   - Найдите папку с виджетами (например: `C:\{свой путь}\Yandex-Music-Widget-for-OBS\designs\`)
   - Выберите папку с нужным виджетом (например: `EvT (Pulsma)`)
   - Откройте файл `index.html`
   - Или скопируйте путь из страницы предпросмотра (`preview.html`) — там есть кнопка "Скопировать путь"

4. **Настройте размер**
   - В настройках Browser Source укажите ширину и высоту
   - Рекомендуемые размеры указаны на странице предпросмотра для каждого виджета
   - Или просто перетащите углы виджета в OBS, чтобы изменить размер

5. **Готово!**
   - Виджет появится в OBS и начнёт показывать информацию о текущем треке
   - Если трек не отображается, убедитесь, что PulseSync запущен и Яндекс.Музыка играет

### Полезные советы:

- **Позиционирование**: Многие виджеты поддерживают параметры `?position=top-left&offsetX=25&offsetY=25` для изменения позиции
- **Прозрачность**: Некоторые виджеты поддерживают параметр `?fade=0.8` для настройки прозрачности фона
- **Авто-цвет**: Виджет может автоматически подбирать цвет фона под обложку трека
- **Авто-размер**: Виджет может автоматически подстраивать размер под длину названия трека

Все эти настройки можно изменить прямо на странице предпросмотра (`preview.html`)!

## Доступные виджеты

В проекте есть несколько готовых дизайнов на выбор:

- **EvT (Pulsma)** — классический виджет с анимацией текста и авто-подбором цвета
- **Battlebeats Classic Card** — карточка в стиле Battlebeats
- **LeftBar** — вертикальная панель слева
- **Strofi** — красивый виджет с каруселью обложек и анимациями
- **Get Track Test** — виджет для разработчиков, показывает всю доступную информацию о треке

Откройте `preview.html` в браузере, чтобы увидеть все виджеты и выбрать подходящий!

## Частые вопросы

**Q: Виджет не показывает трек, что делать?**  
A: Убедитесь, что:
- PulseSync запущен и работает
- Яндекс.Музыка открыта и играет трек
- В OBS указан правильный путь к файлу `index.html`

**Q: Можно ли использовать виджет не в OBS?**  
A: Да! Вы можете открыть `index.html` в любом браузере или разместить виджет на веб-сервере.

**Q: Как изменить позицию виджета на экране?**  
A: Многие виджеты поддерживают параметры в URL:
- `?position=top-left` — позиция (top-left, top-right, bottom-left, bottom-right, center)
- `?offsetX=25&offsetY=25` — отступы от краёв в пикселях

**Q: Виджет слишком большой/маленький**  
A: В OBS вы можете изменить размер Browser Source, перетащив его углы или указав точные размеры в настройках.

**Q: Где взять PulseSync?**  
A: Скачайте с официального сайта: [pulsesync.dev](https://pulsesync.dev/)

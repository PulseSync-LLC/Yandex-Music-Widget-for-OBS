Yandex Music Widgets

Как пользоваться

Виджеты Yandex Music предназначены для отображения текущего трека в OBS Studio или других приложениях, поддерживающих Browser Source.

  1. Установите PulseSync — приложение для синхронизации с Яндекс.Музыкой. Скачать можно на сайте pulsesync.dev
  2. Запустите PulseSync — убедитесь, что приложение запущено и работает. Виджеты автоматически подключаются к локальному серверу приложения через http://127.0.0.1:2007/get_track
  3. Добавьте виджет в OBS — откройте OBS Studio, добавьте Browser Source и укажите путь к файлу index.html выбранного виджета. Используйте кнопку "Копировать путь" для удобства.
  4. Настройте размер — отрегулируйте размер Browser Source в OBS под ваши нужды. Виджет будет автоматически обновляться и показывать текущий трек.

Пример пути: file:///C:/Project/designs/EvT (Pulsma)/index.html

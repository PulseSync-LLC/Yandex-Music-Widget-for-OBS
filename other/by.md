## Што гэта такое?

Гэта набор прыгожых віджетов для OBS Studio, якія паказваюць інфармацыю пра трэк, які зараз грае ў Яндекс.Музыке. Віджет аўтаматычна абнаўляецца і адлюстроўвае:
- Назву трэка
- Выканаўцу
- Вокладку альбома
- Статус прайгравання (грае, на паузе і г.д.)
- Прагрэс трэка

## Што трэба для працы?

**Усяго 2 простых крокі:**

1. **Усталюйце PulseSync**
   - Спампуйце праграму з афіцыйнага сайта: [pulsesync.dev](https://pulsesync.dev/)
   - Усталюйце яе на камп'ютар
   - Запусціце Яндекс.Музыку і PulseSync адначасова

2. **Выберыце віджет**
   - Адкрыйце файл `preview.html` у браўзэры, каб паглядзець усе даступныя віджеты
   - Выберыце спадабаўшыся дызайн

**Гатова!** Больш нічога наладжваць не трэба. Віджет аўтаматычна падключыцца да PulseSync і пачне паказваць інфармацыю пра трэкі.

## Як дадаць віджет у OBS?

### Пашагавая інструкцыя:

1. **Адкрыйце OBS Studio**
   - Запусціце праграму OBS на вашым камп'ютары

2. **Дадайце Browser Source**
   - У спісе крыніц (унізе экрана) націсніце кнопку **"+"** (плюс)
   - Выберыце **"Browser Source"** (Браўзерная крыніца)
   - Дайце яму назву, напрыклад: "Яндекс Музыка"

3. **Пакажыце шлях да віджета**
   - У наладах Browser Source знайдзіце поле **"Local file"** (Лакальны файл)
   - Націсніце кнопку **"Browse"** (Агляд)
   - Знайдзіце папку з віджетамі (напрыклад: `C:\{свой шлях}\Yandex-Music-Widget-for-OBS\designs\`)
   - Выберыце папку з патрэбным віджетам (напрыклад: `EvT (Pulsma)`)
   - Адкрыйце файл `index.html`
   - Або скапіюйце шлях са старонкі папярэдняга прагляду (`preview.html`) — там ёсць кнопка "Скапіраваць шлях"

4. **Наладзьце памер**
   - У наладах Browser Source пакажыце шырыню і вышыню
   - Рэкамендаваныя памеры паказаны на старонцы папярэдняга прагляду для кожнага віджета
   - Або проста перацягніце вуглы віджета ў OBS, каб змяніць памер

5. **Гатова!**
   - Віджет з'явіцца ў OBS і пачне паказваць інфармацыю пра бягучы трэк
   - Калі трэк не адлюстроўваецца, пераканайцеся, што PulseSync запушчаны і Яндекс.Музыка грае

### Карысныя парады:

- **Пазіцыянаванне**: Многія віджеты падтрымліваюць параметры `?position=top-left&offsetX=25&offsetY=25` для змены пазіцыі
- **Празрыстасць**: Некаторыя віджеты падтрымліваюць параметр `?fade=0.8` для наладкі празрыстасці фону
- **Аўта-колер**: Віджет можа аўтаматычна падбіраць колер фону пад вокладку трэка
- **Аўта-памер**: Віджет можа аўтаматычна падстройваць памер пад даўжыню назвы трэка

Усе гэтыя налады можна змяніць прама на старонцы папярэдняга прагляду (`preview.html`)!

## Даступныя віджеты

У праекце ёсць некалькі гатовых дызайнаў на выбар:

- **EvT (Pulsma)** — класічны віджет з анімацыяй тэксту і аўта-падборам колеру
- **Battlebeats Classic Card** — картка ў стылі Battlebeats
- **LeftBar** — вертыкальная панэль злева
- **Strofi** — прыгожы віджет з каруселлю вокладак і анімацыямі
- **Get Track Test** — віджет для распрацоўшчыкаў, паказвае ўсю даступную інфармацыю пра трэк

Адкрыйце `preview.html` у браўзэры, каб убачыць усе віджеты і выбраць патрэбны!

## Структура праекта

```
Yandex-Music-Widget-for-OBS/
├─ designs/              # Папка з усімі віджетамі
│   ├─ EvT (Pulsma)/    # Віджет "Pulsma Bar"
│   ├─ Battlebeats/     # Віджет "Battlebeats Classic Card"
│   ├─ LeftBar/         # Віджет "LeftBar"
│   ├─ Strofi/          # Віджет "Strofi"
│   └─ getTrackTest/    # Віджет для распрацоўшчыкаў
├─ preview.html         # Старонка папярэдняга прагляду ўсіх віджетов
├─ api.js               # Файл для падключэння да PulseSync
└─ readme.md            # Гэты файл
```

**Для звычайных карыстальнікаў:** Вам не трэба разбірацца ў структуры файлаў! Проста выкарыстоўвайце `preview.html` для выбару віджета і прытрымлівайцеся інструкцыі вышэй.

## Хочаце стварыць свой дызайн?

Мы **прывітаем** розныя стылі афармлення! Калі ў вас ёсць ідэі — зрабіце свой варыянт, стварыце **Pull Request** у гэтым рэпазіторыі, і мы дадамо новую тэму ў папку `designs/`.

### Прыклад структуры новага віджета:

```
designs/
  MyAwesomeDesign/      # Назва вашага віджета
    ├─ index.html       # Асноўная старонка віджета
    ├─ style.css        # Стылі афармлення
    ├─ main.js          # Логіка працы віджета
    └─ default.png      # Заглушка для вокладкі (калі трэк не грае)
```

Вы можаце назваць сваю папку як заўгодна і стварыць любы дызайн!

## Частыя пытанні

**П: Віджет не паказвае трэк, што рабіць?**  
А: Пераканайцеся, што:
- PulseSync запушчаны і працуе
- Яндекс.Музыка адкрытая і грае трэк
- У OBS паказаны правільны шлях да файла `index.html`

**П: Ці можна выкарыстоўваць віджет не ў OBS?**  
А: Так! Вы можаце адкрыць `index.html` у любым браўзэры або размясціць віджет на вэб-серверы.

**П: Як змяніць пазіцыю віджета на экране?**  
А: Многія віджеты падтрымліваюць параметры ў URL:
- `?position=top-left` — пазіцыя (top-left, top-right, bottom-left, bottom-right, center)
- `?offsetX=25&offsetY=25` — адступы ад краёў у пікселях

**П: Віджет занадта вялікі/маленькі**  
А: У OBS вы можаце змяніць памер Browser Source, перацягнуўшы яго вуглы або паказаўшы дакладныя памеры ў наладах.

**П: Дзе ўзяць PulseSync?**  
А: Спампуйце з афіцыйнага сайта: [pulsesync.dev](https://pulsesync.dev/)
